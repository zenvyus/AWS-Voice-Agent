# Glossary

| Term | Definition |
|------|-----------|
| **Barge-in** | When a caller speaks while the agent is still playing audio, interrupting the current response. |
| **Contact Flow** | Amazon Connect's visual scripting model for defining call routing and handling logic. |
| **Filler Audio** | Pre-synthesised short phrases (e.g., "Let me check that for you") played to mask latency during tool calls. |
| **Gate (Speech Quality)** | One of four sequential filters applied to STT transcripts to reject noise before sending to the LLM. |
| **IATA Code** | Three-letter airport identifier (e.g., SYD, JFK, LHR). |
| **KVS** | Amazon Kinesis Video Streams — used for bidirectional audio transport between Connect and the orchestrator. |
| **Noise Monitor** | A Step Functions state machine that tracks speech rejection rates and triggers a spoken intervention when persistent noise is detected. |
| **OrderID** | A 6-character alphanumeric booking reference generated by the create_booking tool. |
| **Orchestrator** | The Fargate Python service that manages the real-time audio loop for each call. |
| **PCM** | Pulse Code Modulation — the raw audio format (16-bit signed LE, 8 kHz mono) used throughout the pipeline. |
| **Rachel** | The AI agent persona — a professional airline customer service representative. |
| **RAG** | Retrieval-Augmented Generation — using Bedrock Knowledge Bases to ground LLM responses in source documents. |
| **STT** | Speech-to-Text (Amazon Transcribe). |
| **TTS** | Text-to-Speech (Amazon Polly). |
